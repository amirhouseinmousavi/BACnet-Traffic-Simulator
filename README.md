# Multi-Scenario BACnet Traffic Simulator  

A simulation tool for generating **normal** and **attack** BACnet traffic in Building Automation Systems (BAS).  
This software supports research on HVAC security, anomaly detection, cryptographic evaluation, and IDS/IPS benchmarking.

---

## ✨ Key Features
- Generates realistic BACnet traffic based on real BAS sensor data  
- Supports multiple attack scenarios:
  - Data falsification  
  - Data modification  
  - Covert channel attacks (plaintext, encrypted, hashed)
- Produces both normal and malicious BACnet NPDU/APDU patterns  
- Ideal for IDS/IPS testing, anomaly detection, and cybersecurity evaluations  
- Full Python implementation using BAC0, bacpypes and Cryptodome
